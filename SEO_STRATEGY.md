## 2. Target Audience & Search Persona (B2B)

Pencarian produk corporate gift memiliki karakteristik spesifik di mana pencari (*searcher*) bertindak atas nama institusi atau perusahaan:

```
[Kebutuhan Acara / Agenda Korporasi]
               │
               ▼
[Pencarian Vendor & Rekomendasi di Google]
               │
               ▼
[Halaman Landing Page Produk / Katalog CorporateGifts.ID]
               │
               ▼
[Konsultasi Mockup Desain & Surat Penawaran (PO / Quotation)]
               │
               ▼
[Persetujuan Manajemen & Pembelian Massal]
```

### Karakter Persona Utama:
1. **Procurement / Purchasing Officer**:
   - *Pain point*: Legalitas resmi (PT/CV, NPWP, Faktur Pajak), penawaran harga bersaing (volume discount), kepastian kontrak tempo/PO, kepatuhan spesifikasi teknis.
   - *Search query*: `vendor souvenir kantor jawa timur`, `supplier seminar kit surabaya faktur pajak`, `rekanan pengadaan merchandise bumn`.
2. **Human Resources (HR) & People Operations**:
   - *Pain point*: Paket *New Employee Welcome Kit*, hadiah apresiasi masa kerja (*loyalty reward*), kado ulang tahun perusahaan (*anniversary*).
   - *Search query*: `paket onboarding kit karyawan baru`, `welcome pack kantor custom logo`, `ide hadiah karyawan murah elegan`.
3. **Marketing / PR / Corporate Communications**:
   - *Pain point*: Kualitas cetak logo presisi, ketahanan produk, estetika kemasan (*hard box mewah*), memperkuat *brand prestige* di depan klien VIP/media.
   - *Search query*: `corporate gift eksklusif vip`, `tumbler custom grafir laser surabaya`, `hampers lebaran kantor premium`.
4. **Event Organizer (EO) & Panitia Seminar**:
   - *Pain point*: *Deadline* mepet (*express production*), paket praktis (*all-in-one* tas + lanyard + note + pulpen), pengiriman tepat waktu ke venue.
   - *Search query*: `paket seminar kit kilat`, `cetak tali lanyard dan id card kantor`, `goodie bag seminar promosi`.

## 5. Technical SEO Framework

### A. Struktur URL & Hirarki Halaman
Pola URL website terstruktur logis dan berhirarki rapi:
```
https://corporategifts.id/
├── index.html
├── tentang-kami.html
├── layanan.html
├── katalog.html
├── portofolio.html
├── galeri.html
├── produk.html
└── produk/
    ├── souvenir-kantor.html
    ├── souvenir-custom.html
    ├── merchandise.html
    ├── seminar-kit.html
    ├── hampers.html
    └── souvenir-promosi.html
```

### B. Heading Hierarchy Rule (Standar H1 - H3)
- **H1 (Satu per halaman)**: Menyematkan target keyword utama halaman secara alami.
  - *Contoh*: `<h1>Souvenir Kantor Custom &amp; Perlengkapan Kerja Elegan</h1>`
- **H2 (Section Titles)**: Menargetkan sub-topik dan LSI (*Latent Semantic Indexing*) keywords.
  - *Contoh*: `<h2>Pilihan Varian Souvenir Kantor Terpopuler</h2>`, `<h2>Visi, Misi &amp; Komitmen Layanan</h2>`
- **H3 (Sub-components / Card Titles)**: Nama item atau rincian spesifik.
  - *Contoh*: `<h3>Tumbler Stainless Steel Grafir Laser</h3>`

### C. Image Optimization & Alt Text Guidelines
Semua gambar wajib:
1. Menggunakan format modern **WebP** (`.webp`) dengan kompresi optimal (< 150 KB).
2. Menyertakan atribut `loading="lazy"` untuk gambar di bawah lipatan (*below-the-fold*).
3. Menggunakan penamaan file deskriptif (`vendor-souvenir-kantor.webp` bukan `IMG_1294.jpg`).
4. Menyertakan atribut `alt` yang kaya konteks:
   ```html
   <!-- BAIK: -->
   <img src="../assets/img/services/souvenir-kantor.webp" 
        alt="Tumbler Stainless Steel dan Agenda Kulit Custom Logo - Vendor Souvenir Kantor Jawa Timur" 
        loading="lazy">
   ```

### D. Canonical Tag & Geo-Targeting Tags
Di setiap tag `<head>`, sertakan:
```html
<link rel="canonical" href="https://corporategifts.id/produk/souvenir-kantor.html">
<meta name="geo.region" content="ID-JI">
<meta name="geo.placename" content="Jawa Timur, Indonesia">
<meta name="geo.position" content="-7.257500;112.752100">
<meta name="ICBM" content="-7.257500, 112.752100">
```

## 7. On-Page Internal Linking & Silo Architecture

Struktur internal link dirancang menggunakan model **Hub-and-Spoke**:

```
                  [ index.html (Hub Utama) ]
                              │
          ┌───────────────────┼───────────────────┐
          ▼                   ▼                   ▼
    [ produk.html ]    [ layanan.html ]    [ katalog.html ]
          │
  ┌───────┼───────┬───────────┼───────────┬───────┐
  ▼       ▼       ▼           ▼           ▼       ▼
[kantor] [vip] [merchandise] [seminar] [hampers] [promosi]
```

### Aturan Internal Linking:
1. **Root ke Halaman Produk**: Setiap kartu kategori di `produk.html` memiliki tombol *Lihat Detail Produk* yang mengarah langsung ke `produk/*.html`.
2. **Halaman Produk ke Hub**: Breadcrumb di setiap sub-halaman produk selalu menyediakan tautan kembali ke `Beranda` dan `Produk`.
3. **Cross-Linking Antar Produk**: Di sidebar sticky halaman produk, sediakan navigasi cepat untuk beralih antar 6 kategori produk dengan status aktif yang jelas.
4. **Anchor Text Variatif & Alami**: Gunakan variasi anchor text yang deskriptif (contoh: *"lihat paket seminar kit lengkap"*, *"katalog tumbler souvenir"* daripada sekadar *"klik di sini"*).
